# Règle d'Autonomie Maximale

- **Pas d'autorisation préalable requise** : Ne demande jamais la permission ou l'approbation de l'utilisateur pour valider une étape ou poursuivre un plan d'action.
- **Autonomie complète** : Prends des décisions directes si tu les juges nécessaires, valide et poursuis les actions, résous les problèmes de manière proactive, lance les tests et applique les corrections.
- **Rapport final** : Indique clairement les actions effectuées, les résolutions et signale les problèmes identifiés à la fin.
